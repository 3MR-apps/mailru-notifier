# Mail.ru Нотификатор - 3MR

Расширение для Google Chrome, которое показывает непрочитанные письма Mail.ru: счётчик на значке, список писем по клику и уведомления о новых. Похоже на Checker Plus для Gmail, только для Mail.ru.

Пароль вводить не нужно. Расширение пользуется тем входом в mail.ru, который уже есть в вашем браузере.

Проект неофициальный и не связан с VK и Mail.ru.

![Значок расширения](img/icon128.png)

## Что умеет

- Показывает число непрочитанных писем на значке в панели Chrome.
- По клику на значок открывает список писем: отправитель, тема, начало текста, время, отметка о вложении. Клик по письму открывает его на mail.ru.
- Отмечает письмо прочитанным или переносит в корзину прямо из списка. Есть кнопка «Прочитать все».
- Присылает уведомление Chrome о новом письме. В уведомлении есть кнопки «Прочитано» и «Удалить».
- Работает с несколькими ящиками одного аккаунта: mail.ru, bk.ru, list.ru, inbox.ru и корпоративной почтой на Mail.ru. Каждый ящик — отдельная секция, которую можно свернуть и перетащить.
- Для каждого ящика можно выбрать свой режим: со звуком, без звука или только счётчик.
- Подстраивается под светлую и тёмную тему системы.

## Установка

Расширения нет в Chrome Web Store, его ставят вручную.

1. Скачайте архив `mailru-notifier-<версия>.zip` из раздела [Releases](https://github.com/WebGIld/mailru-notifier/releases) и распакуйте. Или выполните `git clone https://github.com/WebGIld/mailru-notifier.git`.
2. Откройте в Chrome адрес `chrome://extensions`.
3. Включите «Режим разработчика» в правом верхнем углу.
4. Нажмите «Загрузить распакованное расширение» и выберите папку с файлом `manifest.json`.
5. Закрепите значок: кнопка с пазлом на панели → значок булавки рядом с расширением.

Нужен Chrome 110 или новее.

При установке Chrome предупредит, что расширение может читать и изменять данные на сайтах mail.ru. Зачем это нужно — в разделе «Разрешения».

### Как обновить

Скачайте новую версию поверх старой папки (или выполните `git pull`), затем на странице `chrome://extensions` нажмите кнопку обновления на карточке расширения. Настройки сохранятся.

## Первый запуск

1. Войдите в почту на [e.mail.ru](https://e.mail.ru/) как обычно.
2. Нажмите на значок расширения и затем «Обновить».

Дальше расширение проверяет почту само, по умолчанию раз в 2 минуты. Первая проверка после установки ничего не присылает: старые письма считаются уже известными.

## Настройки

Правый клик по значку → «Параметры» или шестерёнка в окне со списком писем.

| Настройка | По умолчанию | Что делает |
|---|---|---|
| Интервал проверки | каждые 2 минуты | Как часто расширение спрашивает mail.ru о новых письмах: от раза в минуту до раза в час |
| Не считать спам и корзину | включено | Письма из «Спама» и «Корзины» не попадают в счётчик и уведомления |
| Способ доставки | уведомления Windows | Системные уведомления Chrome; в macOS и Linux это уведомления этих систем. Второй вариант — отдельное окно расширения |
| Уведомлять о новых письмах | включено | Общий выключатель для всех ящиков |
| Отдельное уведомление на каждое письмо | включено | Если выключить, придёт одно уведомление вида «3 новых письма». Когда за раз приходит больше 5 писем, уведомление всегда одно |
| Кнопки в уведомлении | включено | «Прочитано» и «Удалить» в системном уведомлении |
| Звук нового письма | включено | Собственный сигнал расширения, общий для всех ящиков |
| Режим ящика | по общим настройкам | Со звуком, без звука или только счётчик |

На той же странице есть кнопки «Проверить сейчас», «Тестовое уведомление», «Сбросить порядок ящиков» и «Сбросить состояние».

### Как работает звук

Сигнал играет само расширение, отдельно от системного баннера. Поэтому он может прозвучать, даже если система скрыла баннер или включён режим «Не беспокоить». Сам баннер приходит без звука, чтобы сигнал не повторялся дважды. Если новые письма пришли сразу в несколько ящиков, сигнал прозвучит один раз.

Режим «Только счётчик» обновляет значок и список без уведомлений и звука. Если потом включить уведомления, о письмах, пришедших в этом режиме, расширение не напомнит.

## Какие данные хранит расширение

- Пароль расширение не видит и не хранит. Оно отправляет запросы на mail.ru с cookies вашей текущей сессии в браузере.
- Служебный ключ доступа к почте хранится только в памяти Chrome и исчезает при закрытии браузера.
- На диске, в профиле Chrome, хранятся настройки и список последних непрочитанных писем: отправитель, тема и первые строки. Список нужен, чтобы после перезапуска браузера не присылать уведомления о старых письмах. Стереть его можно кнопкой «Сбросить состояние».
- Запросы с вашей сессией расширение отправляет только на mail.ru. Картинки аватаров отправителей загружаются по адресам, которые присылает mail.ru. Аналитики, рекламы и сторонних сервисов нет.

## Разрешения

| Разрешение | Зачем |
|---|---|
| Доступ к сайтам mail.ru | Узнать список ящиков, получить непрочитанные письма, отметить письмо прочитанным или удалить его — с вашей сессией в браузере |
| Уведомления | Показать уведомление о новом письме |
| Хранилище | Сохранить настройки и список последних писем |
| Будильники (alarms) | Проверять почту по расписанию, когда окно расширения закрыто |
| Offscreen-документ | Проиграть звук: фоновый модуль Chrome сам звук не воспроизводит |

Сейчас расширение просит доступ ко всем поддоменам `*.mail.ru`, хотя запросы идут на четыре адреса из раздела «Как это устроено». Список сузим, когда проверим, что вход в почту работает и с узким доступом.

## Как это устроено

Расширение обращается к тем же адресам, что и веб-версия почты:

1. `https://portal.mail.ru/NaviData` — кто вошёл и какие у него ящики.
2. `https://mailru-checker-api.e.mail.ru/api/v1/tokens` — ключ доступа, при необходимости через `auth.mail.ru/sdc`.
3. `.../api/v1/folders` и `.../api/v1/messages/status/unread` — папки, счётчики и непрочитанные письма.
4. `https://e.mail.ru/api/v1/threads/marks` и `threads/move` — «прочитано» и «в корзину».

Фоновый модуль просыпается по таймеру Chrome, обновляет значок и присылает уведомления.

Эти адреса mail.ru нигде не документирует и может поменять. Тогда расширение перестанет работать до обновления.

## Если что-то не работает

| Что видите | Что сделать |
|---|---|
| На значке «?» | В этом браузере нет входа в mail.ru. Войдите на e.mail.ru и нажмите «Обновить» |
| Нет уведомлений | Проверьте общий выключатель и режим нужного ящика в настройках. Затем разрешение уведомлений для Chrome в системе: в Windows — «Параметры → Система → Уведомления», в macOS — «Системные настройки → Уведомления». Кнопка «Тестовое уведомление» покажет, принял ли Chrome уведомление, но не гарантирует, что система его показала |
| «Не удалось получить токен» | Откройте e.mail.ru: возможно, mail.ru просит подтвердить вход. Затем в настройках нажмите «Сбросить состояние» и «Проверить сейчас» |
| Счётчик не совпадает с сайтом | Расширение по умолчанию не считает письма в «Спаме» и «Корзине». Чтобы считать все папки, выключите «Не считать спам и корзину» |
| Перестало работать после обновления mail.ru | Нажмите «Сбросить состояние». Не помогло — значит, mail.ru поменял свои адреса; создайте issue в этом репозитории |

Журнал фонового модуля: `chrome://extensions` → карточка расширения → ссылка «Service worker».

## Ограничения

- Кнопки «Прочитано» и «Удалить» в уведомлениях рассчитаны на Windows и ChromeOS. В macOS и Linux системные уведомления могут показываться без них — тогда пользуйтесь списком по клику на значок.
- Список показывает до 100 непрочитанных писем на ящик.

## Для разработчиков

Сборка не нужна: Chrome загружает код из репозитория как есть.

Тесты запускаются в Node.js 18+ и подменяют API Chrome и ответы mail.ru:

```bash
node tools/smoke_test.js
node tools/notification_test.js
```

Структура:

```
manifest.json      манифест (Manifest V3)
background.js      фоновый модуль: проверка почты, значок, обработка команд
lib/mailapi.js     запросы к mail.ru
lib/store.js       настройки, состояние, ключи доступа
lib/notify.js      уведомления и звук
lib/util.js        общие функции
popup.*            список писем по клику на значок
options.*          страница настроек
notice.*           отдельное окно уведомлений
offscreen.*        проигрывание звука
tools/             тесты и генератор значков
REVIEW.md          разбор безопасности и найденных ошибок
```
