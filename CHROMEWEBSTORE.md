**Подробное описание** (магазин не понимает Markdown — вставлять как обычный текст)

```
Показывает непрочитанные письма Mail.ru прямо в Chrome: число на значке, список писем по клику и уведомление о каждом новом письме.

Расширение неофициальное и не связано с VK и Mail.ru.

ЧТО УМЕЕТ
• Число непрочитанных писем на значке в панели браузера.
• Список писем по клику на значок: отправитель, тема, начало текста, время, отметка о вложении. Клик по письму открывает его на mail.ru.
• Отметить письмо прочитанным или перенести в корзину прямо из списка; кнопка «Прочитать все».
• Уведомление о новом письме с кнопками «Прочитано» и «Удалить».
• Несколько ящиков одного аккаунта: mail.ru, bk.ru, list.ru, inbox.ru и корпоративная почта на Mail.ru. Каждый ящик — отдельная секция, её можно свернуть и перетащить.
• Свой режим для каждого ящика: со звуком, без звука или только счётчик.
• Светлая и тёмная тема — как в системе.

КАК ПОЛЬЗОВАТЬСЯ
1. Войдите в почту на e.mail.ru как обычно.
2. Нажмите на значок расширения, затем «Обновить».
3. Дальше расширение проверяет почту само — по умолчанию раз в 2 минуты. Интервал меняется в настройках.

КОНФИДЕНЦИАЛЬНОСТЬ
Пароль не нужен: расширение пользуется входом в Mail.ru, который уже есть в браузере. Список писем хранится только на вашем компьютере, ключ доступа к почте — только в памяти браузера до его закрытия. Расширение обращается только к серверам mail.ru. Нет своего сервера, аналитики и рекламы.
Политика конфиденциальности: https://github.com/3MR-apps/mailru-notifier/blob/main/PRIVACY.md

Исходный код и вопросы: https://github.com/3MR-apps/mailru-notifier
```

## Обоснование разрешений

| Разрешение | Тип | Обоснование |
|---|---|---|
| `alarms` | permissions | Проверять почту по расписанию (раз в 1–60 минут, по выбору пользователя), когда окно расширения закрыто, и обновлять число на значке. |
| `notifications` | permissions | Показывать уведомление о новом письме с кнопками «Прочитано» и «Удалить». Пользователь может выключить уведомления в настройках. |
| `storage` | permissions | Хранить настройки (в том числе режим и порядок каждого ящика по его адресу) и список последних непрочитанных писем — чтобы показать их в окне расширения и после перезапуска браузера не уведомлять о старых письмах. Ключ доступа к почте хранится только в памяти сессии. |
| `offscreen` | permissions | Проигрывать короткий звуковой сигнал о новом письме: фоновый модуль расширения сам звук воспроизводить не может. Сигнал выключается в настройках. |
| `https://portal.mail.ru/*` | host_permissions | Узнать, вошёл ли пользователь в Mail.ru, и получить список его ящиков. |
| `https://auth.mail.ru/*` | host_permissions | Получить ключ доступа к почте через вход, уже открытый в браузере (пароль не используется). |
| `https://mailru-checker-api.e.mail.ru/*` | host_permissions | Получить папки, число непрочитанных и список непрочитанных писем. |
| `https://e.mail.ru/*` | host_permissions | По команде пользователя отметить письмо прочитанным или перенести в корзину. |

**Удалённый код** (поле Remote code): нет. Весь код находится в пакете расширения.

## Использование данных (анкета Privacy practices)

Расширение не передаёт данные разработчику и третьим лицам. Магазин просит отметить данные, которые расширение обрабатывает, поэтому отмечаем:

| Тип данных | Отметить | Зачем |
|---|---|---|
| Персональные данные (Personally identifiable information) | да | Адреса почтовых ящиков пользователя, имена и адреса отправителей — чтобы показать письма по ящикам |
| Данные аутентификации (Authentication information) | да | Ключ доступа к почте, полученный через открытый вход; хранится только в памяти браузера |
| Личная переписка (Personal communications) | да | Отправитель, тема и первые строки непрочитанных писем — чтобы показать их в списке и уведомлении |
| Содержимое сайтов (Website content) | да | Темы, начало текста писем и аватары, полученные с mail.ru, — для списка и уведомлений |
| Здоровье, финансы, местоположение, история браузера, действия пользователя | нет | — |

Подтвердить все три пункта:
- данные не продаются третьим лицам;
- данные не используются для целей, не связанных с основной функцией;
- данные не используются для оценки кредитоспособности.

**Политика конфиденциальности**: https://github.com/3MR-apps/mailru-notifier/blob/main/PRIVACY.md

## Заметки для проверки

- Расширение работает с внутренними веб-адресами mail.ru, которыми пользуется сам сайт. Если mail.ru их поменяет, расширение перестанет получать письма до обновления.
- Кнопки в уведомлениях рассчитаны на Windows и ChromeOS.
- Для проверки нужен вход в любой ящик Mail.ru в том же профиле Chrome.
